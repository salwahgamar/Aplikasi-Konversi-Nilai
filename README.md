# Aplikasi Catatan Harian

Aplikasi ini dibuat untuk memenuhi syarat tugas dengan fitur:

- Tambah catatan harian
- Tampilkan daftar catatan
- Edit catatan
- Hapus catatan dengan konfirmasi
- Pencarian berdasarkan judul atau isi catatan
- Kategori / tag untuk catatan
- Mode dark / light UI
- Fetch API eksternal dengan loading dan error handling
- Responsive untuk tampilan mobile dan desktop

## Cara Menjalankan

1. Buka file `index.html` di browser.
2. Aplikasi akan dimuat langsung tanpa instalasi.

## Struktur File

- `index.html` — halaman utama aplikasi.
- `style.css` — gaya tampilan responsive dan mode gelap.
- `app.js` — logika React + kelas `NoteStore` + fetch API.

## Catatan Commit

Gunakan pesan commit rapi, misalnya:

- `feat: tambah aplikasi catatan harian dengan fitur CRUD`
- `fix: perbaiki mode dark dan pencarian catatan`
- `style: perbarui tampilan responsif dan layout`
